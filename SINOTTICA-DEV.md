# N.I. SINOTTICA — sviluppo isolato

Questo branch ospita lo sviluppo della carta sinottica originale Nowcasting Italia.

- Nessuna modifica al ramo main senza approvazione.
- Base cartografica autonoma: Natural Earth, senza CARTO.
- Livelli meteorologici da dati verificabili, senza fronti inventati.
- Isobare, fronti e jet stream saranno implementati e testati separatamente.
- L'integrazione nella Dashboard avverrà solo dopo verifica.

Stato: branch di sviluppo inizializzato; sistema meteorologico non ancora operativo.
